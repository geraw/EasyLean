# תכנית בלוקים להוכחות ב-Lean (לוגיקה ותורת הקבוצות)

<div dir="rtl">

מסמכי התכנון של EasyLean: אילו בלוקי Blockly נדרשים ללימוד אסטרטגיות הוכחה בקורס לוגיקה ותורת הקבוצות, איך כל יחידה בנויה, ואיזה כלים נדרשים כדי שהבלוקים יפיקו ויאמתו קוד Lean.

דרישות הקורס, עקרונות העיצוב וההחלטות מתועדים כאן, יחד עם הקוד, כדי שהתכנון לא יהיה תלוי במסמך חיצוני ושינוי ביחידה יעדכן את המסמך שלה באותו PR.
אב-טיפוס מוקדם ליחידה 2 נמצא בפרויקט הנפרד `proof-blocks-tutorial` (Blockly 12 + Lean 4); המימוש עצמו הוא EasyLean.

## מבנה

בענף הזה יש רק יחידות 1–6, הנושאים של ההרצאה הראשונה בקורס (קשרים, כמתים ומבני הוכחה), בסדר שלה: קודם טבלאות אמת (יחידה 1), ואחר כך הוכחות, שנפתחות בהיכרות עם מסך ההוכחות (שלב 2.1). היחידות המתקדמות (קבוצות, יחסים, פונקציות ואינדוקציה) נמצאות בענף `main`.

כל יחידה מתועדת בקובץ משלה, ומספר הקובץ הוא מספר היחידה. המסמכים הכלליים נמצאים בתיקייה `design/`.

בכל מסמך יחידה, כל שלב מתואר בנפרד: מה לומדים בו, למה הוא בנוי כך (השיקול הדידקטי), איך אנחנו רוצים שסטודנטים יפתרו אותו (צילום מסך לכל פתרון, ולפעמים כמה פתרונות), ושיקולים ושאלות שעוד צריך להכריע. שאלות שנוגעות ליחידה כולה מרוכזות בסופה.

הפתרונות מוגדרים ב־`frontend/e2e/solutions.js`. בדיקה אוטומטית (`solutions.spec.js`) מוודאת שכל פתרון מתקבל ובנוי רק מהבלוקים שבארגז של השלב, ו־`walk.spec.js` עובר על השלבים כמו סטודנט, לפי הרמזים. את הצילומים (בתיקייה `images/`) מחדשים בפקודה `npm run docs:screenshots` בתיקייה `frontend`, כשהשרתים המקומיים רצים.
