# יחידה 3 — שלילה והוכחה בשלילה

<div dir="rtl">

הצעה. הכיתוב הסופי יותאם למוסכמות הקורס. עמודת Lean מציגה את הטקטיקה שהבלוק מייצר.
טקטיקות שמסומנות ב-★ דורשות Mathlib.

## הבלוקים

| אסטרטגיה | כיתוב מוצע | Lean | הערה |
|---|---|---|---|
| הוכחת ¬P | נניח P ונגיע לסתירה | `intro h` | ¬P הוא P → False |
| סתירה מהנחות | ההנחות h1 ו-h2 סותרות | `exact absurd h1 h2` / `contradiction` | סוגר את המטרה |
| הוכחה בשלילה | נניח בשלילה את שלילת המטרה | `by_contra h` | משתמש בלוגיקה קלאסית |
| מסתירה נובע הכול | נעבור להוכיח סתירה | `exfalso` | המטרה הופכת ל-`False` |
| הוכחה בדרך השלילה (קונטרהפוזיטיב) | נוכיח את הגרירה ההפוכה לשלילות | `contrapose!` ★ | אפשר גם `by_contra` ידני |
| פיצול לפי מקרים | נבדוק אם P מתקיים או לא | `by_cases h : P` | שני מקרים |
