# יחידה 5 — קבוצות

<div dir="rtl">

הצעה. הכיתוב הסופי יותאם למוסכמות הקורס. עמודת Lean מציגה את הטקטיקה שהבלוק מייצר.
טקטיקות שמסומנות ב-★ דורשות Mathlib.

## הבלוקים

| אסטרטגיה | כיתוב מוצע | Lean | הערה |
|---|---|---|---|
| הכלה A ⊆ B | יהי x ב-A ונוכיח שהוא ב-B | `intro x hx` | הכלה היא ∀ x, x ∈ A → x ∈ B |
| שוויון A = B | נוכיח שני כיווני הכלה | `ext x` ואז `constructor` | משוואת קבוצות הופכת לשקילות איברים |
| פתיחת הגדרה | נפתח את ההגדרה של איחוד / חיתוך / משלים | `simp only [Set.mem_union, Set.mem_inter_iff, Set.mem_compl_iff]` | רשימת ההגדרות תלויה בבלוק |
| חזקה | x ∈ P(A) פירושו x ⊆ A | `Set.mem_powerset_iff` | |
| שימוש בהנחת הכלה | מכיוון ש-A ⊆ B, גם x ∈ B | `exact h hx` | |

הערה: אחרי פתיחת הגדרה נשארת נוסחה לוגית רגילה, ולכן בלוקי יחידות 2–4 ממשיכים לעבוד.
