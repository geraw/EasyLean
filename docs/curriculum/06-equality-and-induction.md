# יחידה 6 — שוויון ואינדוקציה

<div dir="rtl">

הצעה. הכיתוב הסופי יותאם למוסכמות הקורס. עמודת Lean מציגה את הטקטיקה שהבלוק מייצר.
טקטיקות שמסומנות ב-★ דורשות Mathlib.

## הבלוקים

| אסטרטגיה | כיתוב מוצע | Lean | הערה |
|---|---|---|---|
| החלפה לפי שוויון | נחליף לפי השוויון h | `rw [h]` (או `rw [← h]`) | יש להציג כיוון |
| שרשרת שוויונות | נחשב בשלבים | `calc` | מבנה מקונן |
| סגירה בשוויון זהה | שני הצדדים זהים | `rfl` | |
| אינדוקציה על n | בסיס וצעד האינדוקציה | `induction n with \| zero => … \| succ k ih => …` | שני בלוקי משנה: בסיס, צעד |
| הכנת הנחת עזר | נוכיח טענת עזר | `have h : P := by …` | בלוק מקונן |
