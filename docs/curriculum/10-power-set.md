# יחידה 10 — קבוצת החזקה ופעולות אונריות

<div dir="rtl">

**מטרה:** קבוצות של קבוצות, בסדר של ההרצאה ("קבוצת החזקה" ו"פעולות אונריות" ב־`01-sets.md`): קבוצת החזקה והתכונה `X ∈ 𝒫(A) ⟺ X ⊆ A`, התרגיל `A ⊆ B ⟺ 𝒫(A) ⊆ 𝒫(B)`, `𝒫(A ∩ B) = 𝒫(A) ∩ 𝒫(B)`, ההכלה שכן נכונה באיחוד, והאיחוד והחיתוך האונריים: `⋂X ⊆ A ⊆ ⋃X` כש־A ∈ X, התרגיל `X ⊆ Y → ⋂Y ⊆ ⋂X`, ו־`⋃𝒫(A) = A` כבונוס. ההגדרות שלהן הן טענות "לכל" ו"קיים" על קבוצות, ומשתמשים בהן במהלכים של יחידה 5.

## המהלכים

| מהלך / הגדרה | כשהוא במקומו | Lean |
|---|---|---|
| **טענת עזר** (חדש, 10.4) | "נוכיח קודם את טענת העזר [A ∈ 𝒫(A)]"; בחלק: "נוכיח A ∈ 𝒫(A)"; אחריו: "ומעכשיו A ∈ 𝒫(A) בידינו" | `have : A ∈ 𝒫 A := by …` |
| `X ∈ 𝒫(A)` | לפי הגדרת קבוצת החזקה: `X ⊆ A` | `easylean_mem_powerset` |
| `x ∈ ⋃X` | לפי הגדרת האיחוד האונרי: `∃S (S ∈ X ∧ x ∈ S)` | `easylean_mem_sUnion` |
| `x ∈ ⋂X` | לפי הגדרת החיתוך האונרי: `∀S (S ∈ X → x ∈ S)` | `easylean_mem_sInter` |

השמות "האיחוד האונרי" ו"החיתוך האונרי" הם של ההרצאה (בענף `main`: "איחוד המשפחה"), וגם האות X לקבוצה שאבריה קבוצות. איבר של קבוצת חזקה נקרא X (ואם X תפוס, X₀), וקבוצה שמתקבלת מ"קיים" נקראת S₀ ("נסמן ב־S₀ עצם כזה").

### 10.4: הכיוון השני, בטענת עזר

**למה כך:** בהרצאה משתמשים ביחידון {x}: הוא מוכל ב־A, ולכן ב־B. בבלוקים אין יחידונים, ולכן לוקחים תת־קבוצה אחרת של A, את A עצמה (10.1), כטענת עזר. ההוכחה שונה מזו של ההרצאה, והטקסט אומר זאת.

![10.4](images/unit10-level4-a.png)

### 10.6: ומה עם האיחוד?

**למה כך:** בהרצאה השוויון עם האיחוד מופרך בדוגמה נגדית ({1}, {2}), ונכון רק כש־A ⊆ B או B ⊆ A. דוגמה נגדית אי אפשר לבנות בבלוקים, ולכן השלב מוכיח את ההכלה שנכונה תמיד (הכיוון ⊇ מהשקף), והטקסט מספר על ההפרכה.

![10.6](images/unit10-level6-a.png)

### 10.7: כשהאיחוד כן עובד

**למה כך:** התכנון מבקש "להפריך את הטענה הדומה על איחוד ולהוכיח שזה נכון אם ורק אם A מוכל ב־B או B מוכל ב־A". דוגמה נגדית אי אפשר לבנות בבלוקים (10.6 מספר עליה), והכיוון "אם" אפשר: אם A ⊆ B, אז X ⊆ A ∪ B גורר X ⊆ B, כלומר X ∈ 𝒫(B) ⊆ 𝒫(A) ∪ 𝒫(B). המקרה B ⊆ A סימטרי. **פתרון.** "נניח A ⊆ B.", "יהי X ∈ 𝒫(A ∪ B)", פותחים את ההגדרות, בוחרים את הצד 𝒫(B), "יהי x ∈ X", "מ־X ⊆ A ∪ B נובע x ∈ A ∪ B", חלוקה למקרים לפי ה"או": במקרה x ∈ A, "מ־A ⊆ B נובע x ∈ B", ובמקרה x ∈ B סיימנו.

![10.7](images/unit10-level7-a.png)

### 10.8–10.9: איחוד וחיתוך אונריים

**למה כך:** ההגדרות של ההרצאה כתובות בכמת על קבוצה, `∃A ∈ X (a ∈ A)` ו־`∀A ∈ X (a ∈ A)`; מהלך ההגדרה כותב `∃S (S ∈ X ∧ x ∈ S)` ו־`∀S (S ∈ X → x ∈ S)`. לכן טקסט 10.7 מסביר ש"לכל A ∈ X" פירושו "לכל A, אם A ∈ X אז …" (ו"קיים A ∈ X" פירושו "קיים A כך ש־A ∈ X וגם …"), ושהמשתנה הקשור נקרא S, כי A כבר בידינו; 10.8 מזכיר זאת. גם במצגת נוסף אותו פירוש, בשקף "קבוצות: מושגי יסוד" (2026-10-25). כמו בהרצאה, ⋂X מוגדר רק ל־X לא ריקה; ב־Lean ⋂∅ הוא כל העצמים, ולכן הטקסט וכרטיס ההגדרה אומרים זאת, ו־10.7 מציין ש־A ∈ X ולכן X אינה ריקה.

### 10.10: החיתוך מתהפך

**למה כך:** התרגיל מהשקף "תרגיל לדוגמה" (X ⊆ Y → ⋂Y ⊆ ⋂X), השימוש היחיד בהרצאה בתבנית "להוכיח a ∈ ⋂X: תהי A ∈ X שרירותית". נוסף ב־2026-10-25. טקסט הפתיחה מצטט את ההוכחה מהשקף; הקבוצה השרירותית נקראת S₀, כי בהגדרה הקשור הוא S. השקף מניח ש־X ו־Y לא ריקות; ב־Lean אין בזה צורך.

**פתרון.** "כדי להוכיח ⋂Y ⊆ ⋂X יהי x ∈ ⋂Y ונוכיח x ∈ ⋂X"; "לפי הגדרת החיתוך האונרי, כדי להוכיח x ∈ ⋂X די להוכיח ∀S (S ∈ X → x ∈ S)"; "יהי S₀ שרירותי", ובתוכו "נניח S₀ ∈ X. עלינו להראות x ∈ S₀."; "לפי ההכלה X ⊆ Y ומ־S₀ ∈ X נובע S₀ ∈ Y"; לפי ההגדרה בהנחה x ∈ ⋂Y, "ב־ ∀S (S ∈ Y → x ∈ S) נציב S = S₀"; "מ־(S₀ ∈ Y → x ∈ S₀) ומ־S₀ ∈ Y נקבל x ∈ S₀", וסיום.

![10.10](images/unit10-level10-a.png)

### 10.11: איחוד אונרי של קבוצת החזקה

**למה כך:** בכיוון ⊇ העד בהרצאה הוא היחידון {x}; בבלוקים אין יחידונים, ולכן העד הוא A עצמה (A ∈ 𝒫(A), 10.1), והטקסט אומר זאת. הסיכום מנסח את ההערה של ההרצאה על שני עדים בשמות שונים (S₀, S₁) נכון: בשלב הזה יש רק עד אחד.

## מה מההרצאה לא נכנס, ולמה

- **|𝒫(A)| = 2ⁿ, הכלי האינטראקטיבי, 𝒫({1,2}):** אין ספירה וקבוצות מפורשות.
- **הכיוון "רק אם" של 𝒫(A ∪ B) = 𝒫(A) ∪ 𝒫(B), וההפרכה בדוגמה {1}, {2}:** צריך את הקבוצה {a, b}; הכיוון "אם" הוא 10.7.
- **⋃ ו־⋂ של אוסף שמוגדר בתבנית, דה־מורגן לאונריים, קיום ויחידות של האיחוד והחיתוך, תנאים שקולים ל־X = 𝒫(A):** אין בבלוקים קבוצה מוגדרת בתבנית על קבוצות; חלק מהן אפשריות בעתיד.
