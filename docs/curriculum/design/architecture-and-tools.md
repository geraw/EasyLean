## רכיבים

```
Blockly (בלוקים מותאמים)
   │  עץ בלוקים
   ▼
מחולל Lean  ──►  טקסט טקטיקות
   │
   ▼
מנוע מצב הוכחה  ◄── אחד משני מימושים:
   ├─ A. מנוע JS קטן (פסוקי)
   └─ B. שרת Lean (LSP) – מצבי הוכחה אמיתיים
   │
   ▼
שכבת משוב בעברית  ──►  הודעות, רמזים, סיכום
```

| רכיב | תפקיד | הערה |
|---|---|---|
| בלוקים מותאמים | הגדרת בלוקים עם כיתוב עברי ושדות | קיים ליחידה 1 ב-`blocks.js` |
| מחולל Lean | עץ בלוקים → טקטיקות | קיים ב-`lean-generator.js`; יש להרחיב לבלוקים מקוננים (מקרים, אינדוקציה) |
| מנוע מצב הוכחה | מחשב הנחות ומטרה אחרי כל בלוק; קובע מה מותר לחבר | הרכיב המרכזי החסר |
| שכבת משוב | ממפה כשלים להודעות בעברית | דרישת משוב בעברית |
| שמירה | התקדמות וחזרה לתרגיל | `localStorage` או שרת (החלטה פתוחה) |
| בדיקות | מחולל, מנוע, ותרגילים מול Lean אמיתי | `node --test` + `lean` ב-CI |

## מנוע מצב הוכחה — בחירה

| | A. מנוע JS | B. שרת Lean |
|---|---|---|
| תחום | לוגיקה פסוקית (יחידות 1–3) | כל היחידות (כמתים, קבוצות, שוויון) |
| תשתית | רץ בדפדפן, בלי שרת | שרת Lean + Mathlib, או Lean בדפדפן (WASM) |
| משוב בעברית | שליטה מלאה | דורש מיפוי הודעות Lean |
| דיוק | מוגבל לשפה שהוגדרה | נאמן ל-Lean |
| עלות הקמה | נמוכה | גבוהה (שרת, גרסאות, ביצועים) |

**החלטה:** לבחור ב-B ולעבוד ישירות עם שרת Lean, בכל היחידות. הבלוקים ישתמשו בממשק אחיד (`ProofState`: הנחות, מטרות, שגיאה אחרונה), ושרת Lean יחזיר את מצב המטרות ואת הודעות השגיאה למיפוי בעברית.

## כלים

- **Blockly 12** (כבר בשימוש), עם הגבלת חיבורים לפי מצב ההוכחה (`checks` + בדיקות מותאמות).
- **Lean 4 + elan + Lake**; **Mathlib** מיחידה 4 (`use`, `contrapose!`, `Set` ועוד).
- **Vite** לבנייה (קיים).
- **שרת Lean**: `lake serve` או Lean4Web; מחזיר מצבי מטרה לפי מיקום.
- **בדיקות**: `node --test`, וקבצי `.lean` לכל תרגיל שנבדקים עם `lean`.

## תרגיל כהגדרה

כל תרגיל מוגדר בקובץ אחד (JSON/YAML):

```yaml
id: unit1-step2
statement: "(P → Q) → P → Q"
lean: "theorem step2 (P Q : Prop) : (P → Q) → P → Q"
blocks: [proof_start, assume, apply_implication, exact_hypothesis]
locked: []
hints: [direction, structure, next-step]
reference: "intro h1; intro h2; apply h1; exact h2"
```

כך אפשר לבדוק אוטומטית שהפתרון מתקמפל, ושכל תרגיל פתיר בבלוקים שהוגדרו לו.
